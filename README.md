# Flight Data Analysis & Interactive Dashboard

## Project Overview
This project focuses on cleaning, preprocessing, and analyzing flight data to identify trends in flight performance, delays, and cancellations. An interactive Power BI dashboard was developed to visualize key metrics and support data-driven insights.

## Objectives
- Clean and preprocess raw flight data.
- Perform exploratory data analysis to identify trends and patterns.
- Analyze flight delays, cancellations, and operational performance.
- Build an interactive dashboard for data visualization.

## Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Excel** – Data inspection and preprocessing (if used)
